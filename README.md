# Python-Portfolio
These are projects that I created at Jones College Prep in AP Computer Science Principles 2025-2026.

Project Title: Video Games
Summary: A video game developing company just created a new game. Use their data and reviews from users to help make improvements on the game.
Features: 
You're given a:
-summary of the game
-rating of the game
-feedback from users

Project Title: Adventure
Summary: The program takes a user through a mini adventure, similar to the jungle book. Each choice leads to a new situation using nested if statements.
Features:
-User is given a weapon to protect themself in the jungle
-Uses boolean expressions to help users choose between variations of weapons

Project Title: ATM
Summary: This program stimulates transactions made at an ATM machine.
Features:
-Asks for a start balance
-Asks for deposit amount
-Asks for withdrawl amount

Project Title: Birds (final project)
Summary: Program uses information from a dataset to help users find information on inputted bird name.
Features:
-Image of bird is provided
-Scientific name of bird is provided
-Bird's diet is provided
-Prints bird in each conservation status

Project Title: Calculator
Summary: Program stimulates the actions done by a calculator.
Feature:
-Performs addition 
-Performs subtraction 
-Performs multiplication 
-Performs division 

Project Title: Coffee
Summary: This program uses boolean expressions to help the user find their choice of beverage.
Feature:
-Hot drink recommendations
-Cold drink recommendations
-Sweet drink recommendations
